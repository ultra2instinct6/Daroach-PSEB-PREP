Electric Circuit & Symbols

A circuit is a closed conducting path for current. Learn the standard component symbols.

Standard Circuit Symbols

Cell
Battery
Switch (open)
Resistor
Rheostat
Ammeter
Voltmeter
Component Use / Rule
Cell / Battery Provides the potential difference (voltage)
Ammeter (A) Measures current — connected in series
Voltmeter (V) Measures voltage — connected in parallel
Rheostat Variable resistor — changes the current
Resistor Provides a fixed resistance to the current flow
Switch / Key Opens or closes the circuit
